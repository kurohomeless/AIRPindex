## API

### APIプロバイダー

> **警告:** サードパーティのプロキシやAPIプロバイダーの利用には注意してください。運営者はあなたのIPアドレス、リクエストログ、支払いの詳細にアクセスできるため、あなたのアクティビティと実名が紐づく可能性があります。データ漏洩やユーザー情報の無許可販売のリスクがあります。過去の事例として「Moxxie proxy janitor logs」で検索してみてください。
