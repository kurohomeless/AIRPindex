## Antarmuka (Frontends)

### Antarmuka Cloud (Cloud Frontend)

> **Catatan:** Saat menggunakan platform cloud, anggap saja para developer bisa melihat semua riwayat obrolan Anda dan pertimbangkan apakah Anda nyaman dengan hal tersebut. Gunakan antarmuka lokal jika Anda lebih mengutamakan privasi.

## API

### Penyedia API (API Provider)

> **Peringatan:** Berhati-hatilah dengan proksi pihak ketiga atau penyedia API. Operator dapat mengakses alamat IP, log permintaan, dan detail pembayaran Anda, yang berpotensi menghubungkan aktivitas Anda dengan identitas asli Anda. Kebocoran data atau penjualan informasi pengguna tanpa izin adalah sebuah risiko. Cari 'Moxxie proxy janitor logs' untuk contoh insiden di masa lalu.

- **[Chutes](https://chutes.ai/pricing) 💲**
  - Langganan $10/bulan. Banyak model. Pembuat Teks, Suara, Video, Musik, dan Gambar.
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini & Gemma. Konteks tinggi, tetapi tidak dapat diandalkan karena spam terus-menerus dan beban berat.
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - $10/bulan. MiniMax M2.7. Rencana ini untuk pemrograman; mungkin bisa untuk RP... jika Anda tidak tertangkap.\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - Langganan $25/bulan. GLM-4.6 & Diffusion V4.5. Gen Teks/Gambar. Anti-sensur, terenkripsi.
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _Langganan $30/bulan. Banyak model. Pembuat teks._
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - PAYG. Mendukung E2EE.
