## الواجهات (Frontends)

### واجهات سحابية (Cloud Frontend)

> **ملاحظة:** عند استخدام المنصات السحابية، افترض أن المطورين يمكنهم رؤية جميع سجلات الدردشة الخاصة بك، وفكّر في مدى ارتيَاحك لذلك. استخدم واجهة محلية إذا كنت تفضل الخصوصية.

- **[janitor](https://janitorai.com/)**
- **[Saucepan](https://saucepan.ai/)**

### واجهات محلية (Local Frontend)

- **[Aventuras](https://github.com/AventurasTeam/Aventuras/releases)** — [Discord](https://discord.gg/aventuras)
  - تركز على المغامرات النصية، وإعدادها أسهل بطريقة ما (مقارنة بـ ST)، وتوفر تطبيقات أساسية لأنظمة Android و Linux و Windows و Mac.
- **[LettuceAI](https://www.lettuceai.app/download)** — [Github](https://github.com/LettuceAI) / [Discord](https://discord.gg/745bEttw2r)
  - نتابع هذا المشروع باهتمام كبير، المطور مجتهد للغاية. شخص واحد ولكنه يطور بسرعة كبيرة + يوفر إرشادات توجيهية للمستخدمين الجدد، ومن الواضح أن المطور يحب مستخدميه. تطبيق أساسي لأنظمة Android و Windows و macOS و Linux.
- **[RisuAI](https://risuai.net/)** — [Github](https://github.com/kwaroran/RisuAI) / [Discord](https://discord.com/invite/Exy3NrqkGm) / [Patreon](https://patreon.com/RisuAI)
- **[SillyTavern](https://docs.sillytavern.app/installation/)** — [Github](https://github.com/SillyTavern/SillyTavern) / [Discord](https://discord.gg/sillytavern) / [Docs](https://docs.sillytavern.app/) / [Donation](https://docs.sillytavern.app/#personal-donations)
- **[TauriTavern](https://tauritavern.github.io/en/downloads/)** ⭐ — [Github](https://github.com/Darkatse/TauriTavern) / [Docs](https://tauritavern.github.io/en/)
  - نسخة مشتقة من SillyTavern (؟) مع لغة Rust. متوفر بصيغة APK و IPA وغيرها.

## واجهة برمجة التطبيقات (API)

### مزودو الـ API

> **تحذير:** توخَّ الحذر عند استخدام البروكسي أو مزودي الـ API من جهات خارجية. يمكن للمشغلين الوصول إلى عنوان IP الخاص بك، وسجلات الطلبات، وتفاصيل الدفع، مما قد يربط نشاطك بهويتك الحقيقية. تسريب البيانات أو بيع معلومات المستخدم دون تصريح هي مخاطر قائمة. ابحث عن 'Moxxie proxy janitor logs' كمثال على حوادث وقعت في الماضي.

- **[Chutes](https://chutes.ai/pricing) 💲**
  - اشتراك بقيمة ١٠ دولارات شهريًا. نماذج عديدة. توليد نصوص، وصوت، وفيديو، وموسيقى، وصور.
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini و Gemma. سياق عالٍ، ولكن لا يمكن الاعتماد عليه بسبب السبام المستمر والضغط الكبير.
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - ١٠ دولارات شهريًا. MiniMax M2.7. الخطة مخصصة للبرمجة؛ قد تعمل مع الـ RP... إذا لم يتم كشفك.\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - اشتراك بقيمة ٢٥ دولارًا شهريًا. GLM-4.6 و Diffusion V4.5. توليد نصوص وصور. ضد الرقابة، ومشفر.
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _اشتراك بقيمة ٣٠ دولارًا شهريًا. نماذج عديدة. توليد نصوص._
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - الدفع حسب الاستخدام. يدعم التشفير من طرف إلى طرف (E2EE).
