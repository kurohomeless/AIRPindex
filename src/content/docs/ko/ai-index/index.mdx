## API

### API 제공업체 (API Provider)

> **경고:** 서드파티 프록시나 API 제공업체를 사용할 때는 주의하십시오. 운영자가 당신의 IP 주소, 요청 로그, 결제 세부 정보를 확인할 수 있으므로 잠재적으로 당신의 활동이 실제 신원과 연결될 수 있습니다. 데이터 유출이나 사용자 정보의 무단 판매 위험이 존재합니다. 과거 발생했던 인시던트 예시를 보려면 'Moxxie proxy janitor logs'를 검색해 보세요.

- **[Chutes](https://chutes.ai/pricing) 💲**
  - 월 $10 구독. 다양한 모델 지원. 텍스트, 음성, 비디오, 음악 및 이미지 생성.
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini 및 Gemma 제공. 콘텍스트 창은 크지만, 끊임없는 스팸 공격과 과부하로 인해 불안정함.
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - 월 $10. MiniMax M2.7 제공. 코딩용 플랜이지만... 걸리지만 않는다면 롤플레잉(RP)에도 작동할 수 있음.\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - 월 $25 구독. GLM-4.6 및 Diffusion V4.5. 텍스트/이미지 생성. 검열 없음, 암호화 적용.
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _월 $30 구독. 다양한 모델 지원. 텍스트 생성._
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - PAYG. 종단간 암호화(E2EE) 지원.
