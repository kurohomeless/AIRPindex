## API

### Tagapagbigay ng API (API Provider)

> **Babala:** Mag-ingat sa mga third-party proxy o mga tagapagbigay ng API. Maaaring ma-access ng mga operator ang iyong IP address, mga log ng kahilingan, at mga detalye ng pagbabayad, na posibleng mag-ugnay sa iyong aktibidad sa iyong totoong pagkakakilanlan. May panganib ng mga pagtagas ng data o hindi awtorisadong pagbebenta ng impormasyon ng user. Maghanap sa internet ng 'Moxxie proxy janitor logs' para sa mga halimbawa ng insidente sa nakaraan.

  - $10/month sub. Maraming modelo. Pagbuo ng Teksto, Boses, Video, Musika, at Larawan.
