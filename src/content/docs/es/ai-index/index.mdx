## API

### API Provider (Proveedores de API)

> **Advertencia:** Ten cuidado con los proxies de terceros o proveedores de API. Los operadores pueden acceder a tu dirección IP, registros de solicitudes y detalles de pago, vinculando potencialmente tu actividad con tu identidad real. Las filtraciones de datos o la venta no autorizada de información de usuarios son riesgos reales. Busca 'Moxxie proxy janitor logs' para ver ejemplos de incidentes del pasado.

- **[Chutes](https://chutes.ai/pricing) 💲**
  - Suscripción de $10/mes. Muchos modelos. Generación de texto, voz, video, música e imágenes.
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini y Gemma. Contexto alto, pero poco confiable debido al spam constante y la alta carga.
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - $10/mes. MiniMax M2.7. El plan es para programar; podría funcionar para RP... si no te atrapan.\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - Suscripción de $25/mes. GLM-4.6 y Diffusion V4.5. Gen. de texto/imagen. Sin censura, encriptado.
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _Suscripción de $30/mes. Muchos modelos. Gen. de texto._
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - PAYG. Soporta E2EE.
