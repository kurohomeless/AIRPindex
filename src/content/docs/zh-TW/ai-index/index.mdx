## 前端介面 (Frontends)

### 雲端前端 (Cloud Frontend)

> **注意：** 使用雲端平台時，請直接假設開發者能看到你所有的聊天日誌（對話紀錄），並衡量自己是否能接受。如果你更注重隱私，請使用本地端前端。

- **[janitor](https://janitorai.com/)**
- **[Saucepan](https://saucepan.ai/)**

### 本地端前端 (Local Frontend)

- **[Aventuras](https://github.com/AventurasTeam/Aventuras/releases)** — [Discord](https://discord.gg/aventuras)
  - 主打文字冒險，在某些方面設定比 ST 更簡單，支援 Android、Linux、Windows、Mac 的原生應用程式。
- **[LettuceAI](https://www.lettuceai.app/download)** — [Github](https://github.com/LettuceAI) / [Discord](https://discord.gg/745bEttw2r)
  - 正帶著極大的興趣關注這個項目，開發者非常勤奮。只有 1 個人卻更新得超快 + 帶有引導式新手教學，看得出來開發者很愛護用戶。支援 Android、Windows、macOS、Linux 的原生應用程式。
- **[RisuAI](https://risuai.net/)** — [Github](https://github.com/kwaroran/RisuAI) / [Discord](https://discord.com/invite/Exy3NrqkGm) / [Patreon](https://patreon.com/RisuAI)
- **[SillyTavern](https://docs.sillytavern.app/installation/)** — [Github](https://github.com/SillyTavern/SillyTavern) / [Discord](https://discord.gg/sillytavern) / [Docs](https://docs.sillytavern.app/) / [Donation](https://docs.sillytavern.app/#personal-donations)
- **[TauriTavern](https://tauritavern.github.io/en/downloads/)** ⭐ — [Github](https://github.com/Darkatse/TauriTavern) / [Docs](https://tauritavern.github.io/en/)
  - SillyTavern 的分支（？）+ Rust。提供 APK、IPA 等格式。

## 接口 (API)

### API 供應商 (API Provider)

> **警告：** 使用第三方代理或 API 供應商時請務必小心。營運商可以獲取你的 IP 地址、請求日誌和付款明細，這有可能將你的活動與你的真實身份聯繫起來。數據洩露或未經授權販售用戶資訊都是潛在風險。可以去搜尋如過去發生的「Moxxie proxy janitor logs」事件。

- **[Chutes](https://chutes.ai/pricing) 💲**
  - 每月 $10 訂閱。提供多種模型。支援文字、語音、影片、音樂和圖片生成。
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini & Gemma。高上下文，但因為常常被垃圾流量灌爆、負載過重，所以不太穩定。
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - 每月 $10。MiniMax M2.7。這方案本來是給寫程式用的；拿來玩角色扮演（RP）大概也行……只要你沒被抓到的話。\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - 每月 $25 訂閱。GLM-4.6 與 Diffusion V4.5。文字/圖片生成。反審查、已加密。
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _每月 $30 訂閱。提供多種模型。文字生成。_
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - PAYG。支援端到端加密（E2EE）。
