## API

### Provedores de API (API Provider)

> **Aviso:** Tenha cuidado com proxies de terceiros ou provedores de API. Os operadores podem acessar seu endereço IP, logs de requisições e detalhes de pagamento, potencialmente vinculando sua atividade à sua identidade real. Vazamentos de dados ou venda não autorizada de informações dos usuários são riscos reais. Pesquise por 'Moxxie proxy janitor logs' para exemplos de incidentes ocorridos no passado.

- **[Chutes](https://chutes.ai/pricing) 💲**
  - Assinatura de $10/mês. Muitos modelos. Geração de Texto, Voz, Vídeo, Música e Imagem.
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini & Gemma. Contexto alto, mas não confiável devido a spam constante e sobrecarga nos servidores.
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - $10/mês. MiniMax M2.7. O plano é voltado para programação; pode funcionar para RP... se você não for pego.\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - Assinatura de $25/mês. GLM-4.6 e Diffusion V4.5. Geração de Texto/Imagem. Sem censura, criptografado.
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _Assinatura de $30/mês. Muitos modelos. Geração de texto._
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - PAYG. Suporta E2EE.
