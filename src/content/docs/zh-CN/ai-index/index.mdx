## 接口 (API)

### API 供应商 (API Provider)

> **警告：** 使用第三方代理或 API 供应商时请务必小心。运营商可以获取你的 IP 地址、请求日志和付款明细，这有可能将你的活动与你的真实身份联系起来。数据泄露或未经授权贩卖用户信息都是潜在风险。可以去搜索如过去发生的“Moxxie proxy janitor logs”事件。

- **[Chutes](https://chutes.ai/pricing) 💲**
  - 每月 $10 订阅。提供多种模型。支持文本、语音、视频、音乐和图片生成。
- **[Google AI Studio](https://aistudio.google.com/api-keys)**
  - Gemini & Gemma。高上下文，但因为经常被垃圾流量灌爆、负载过重，所以不太稳定。
- **[MiniMax](https://platform.minimax.io/subscribe/token-plan) 💲**
  - 每月 $10。MiniMax M2.7。这方案本来是给写代码用的；拿来玩角色扮演（RP）大概也行……只要你没被抓到的话。\*
- **[NovelAI](https://novelai.net/)** 💲 ⭐
  - 每月 $25 订阅。GLM-4.6 与 Diffusion V4.5。文字/图片生成。反审查、已加密。
- **[Synthentic](https://synthetic.new/?referral=51CypgkY6Hsj0Sj) 💲**
  - _每月 $30 订阅。提供多种模型。文本生成。_
- **[Venice](https://venice.ai/chat?ref=tWo90h)**
  - PAYG。支持端到端加密（E2EE）。
